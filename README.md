 # 🎮 AXV Gaming — Portable Control Center

**A modern, cyberpunk-inspired network control center for Windows, powered by Zapret.**

AXV Gaming Control Center transforms complicated command-line network configurations into a clean, user-friendly desktop interface.

Designed for gamers who experience connection failures, unstable game sessions, or network filtering issues.

## ✨ Features

- 🎮 **Game Profiles** — Create and manage configurations for different games.
- 🌐 **IP Manager** — Add, edit, and remove IP addresses and CIDR ranges.
- ⚡ **Engine Control** — Start, stop, and restart the network engine.
- 🛡️ **Network Filtering** — Manage TCP/UDP filters, ports, and IP lists.
- 📊 **Live Dashboard** — Monitor engine status and configuration.
- 🔧 **Diagnostics & Logs** — View troubleshooting information.
- 💾 **Configuration Backup** — Save and restore working settings.
- 🎨 **Cyberpunk Gaming UI** — Dark interface with neon-red styling.
- 📦 **Portable Design** — Designed for straightforward Windows deployment.

## 🎯 AION 2 Connectivity

AXV Gaming Control Center was developed after successfully troubleshooting AION 2 connectivity issues on an Egyptian ISP.

The tested setup allowed AION 2 to connect without using a traditional VPN.

An AION 2 configuration is included as a starting point, but results may vary depending on your ISP, region, and game servers.

**This is not a guaranteed fix for every network or game.**

## 🚀 Getting Started

1. Download the latest Windows build from GitHub Releases.
2. Extract the package if it is provided as a ZIP.
3. Launch AXV Gaming Control Center.
4. Select or configure your game profile.
5. Start the engine and test your connection.

Administrator privileges may be required for network operations.

## ⚙️ Technology

- Platform: Windows
- Interface: Cyberpunk-inspired desktop GUI
- Networking backend: Zapret
- Supported backend used during development: Flowseal Zapret v1.10.3
- No traditional VPN tunnel required
